# Antigravity Adapter

**Status:** Planned. Compatibility has not been tested.

This directory is reserved for Antigravity-native workspace rules, workflows, and skills where the current product supports them.

Before marking this adapter supported:
1. Record the Antigravity version and operating environment.
2. Verify which instruction files and workflow formats it loads.
3. Add a minimal adapter with no duplicate universal policy.
4. Test instruction discovery, task execution, and permission boundaries.
5. Document unsupported features and known limitations.

Do not assume that a generic instruction file is loaded automatically. Do not copy configuration from another harness without checking compatibility.
