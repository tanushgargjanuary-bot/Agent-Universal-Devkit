# Engineering Playbooks

Reusable, cross-project operating standards for AI-assisted engineering.

## Available playbooks
- [Vibe Coding Playbook](VIBE-CODING-PLAYBOOK.md) — project discovery, systems thinking, implementation discipline, verification, Git hygiene, and session continuity.

## How to apply
At the start of every substantial project or coding session:
1. Read this index.
2. Read the relevant playbook(s).
3. Read the target repository's `AGENTS.md`, README, handoff, architecture docs, and contribution instructions.
4. Apply stricter project-specific rules where they differ.
5. Update the target project's continuity record at the end of substantial work.

These playbooks are reusable guidance. They do not replace project-specific requirements or independent verification.
