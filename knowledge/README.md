# Native Engineering Knowledge

This directory contains original, repository-native engineering study material.

Start with `registry.json` to discover available items. Read `docs/KNOWLEDGE-LIBRARY.md` for authoring, retrieval, and quality rules.

## Current collections

- `algorithms/`: complexity analysis, graph traversal, and shortest-path methods.
- `mathematics/`: linear algebra, probability, and optimisation.

## Authoring rules

Every item must state its purpose, prerequisites, activation signals, assumptions, limitations, and sources. Algorithms should include complexity and correctness reasoning. Mathematical methods should define variables, show derivations or reasoning, and include worked examples.

The material must be written for this repository. Do not copy third-party course notes or textbooks. Cite sources used for verification and attribution.

A knowledge item is not approved merely because it has been added to the registry. Review technical accuracy and test examples before changing its status to `approved`.
