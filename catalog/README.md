# Resource Catalog

This catalog is the Devkit's curated index of external open-source repositories,
tools, libraries, frameworks, datasets, and reusable engineering resources.

## Rules

- Link to upstream projects. Do not copy source code by default.
- Record the exact license and link to its source.
- Separate discovery candidates from approved recommendations.
- Record evidence for maintenance, security, compatibility, and capability claims.
- Re-check entries on a schedule. Mark stale entries; do not silently delete them.
- Popularity is a discovery signal, not a quality score.
- Compare alternatives before recommending a resource.
- Recommend a hybrid only when capabilities are complementary and integration cost is justified.
- Never claim a project is secure or maintained without dated evidence.

See `schemas/resource.schema.json` for the machine-readable entry contract.
