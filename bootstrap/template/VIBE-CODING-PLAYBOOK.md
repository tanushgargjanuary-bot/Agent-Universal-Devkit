# Vibe Coding Playbook

This repository follows the Agent-Universal-Devkit Vibe Coding Playbook.

**Canonical playbook:** https://github.com/tanushgargjanuary-bot/Agent-Universal-Devkit/blob/main/playbooks/VIBE-CODING-PLAYBOOK.md

**Detailed master reference:** https://github.com/tanushgargjanuary-bot/Agent-Universal-Devkit/blob/main/playbooks/VIBE-CODING-AGENT-MASTER-PLAYBOOK.md

## Required use

At the start of substantial coding work:
1. Read this pointer and retrieve/read the canonical playbook.
2. Read this repository's `AGENTS.md`, project state, work log, and relevant architecture documentation.
3. Apply the playbook together with project-specific rules. Stricter security, safety, regulatory, and repository rules take precedence.
4. Adapt the workflow to the actual risk and task size. Do not apply irrelevant checklists mechanically.
5. Before completion, verify the work and update the project's continuity records.

## Long-term engineering default

Prefer solutions that improve long-term maintainability, reliability, security, portability, scalability, and recoverability. Proactively identify high-value improvements and include them when they are relevant, proportionate, and within the accepted scope. Do not silently expand scope or add speculative abstractions.

Preserve existing user work. Ask before destructive, irreversible, costly, permission-changing, deployment, publication, or externally consequential actions. Never use blanket rollback commands that could discard unrelated user changes.

## Availability

This file is a lightweight bootstrap pointer, not a vendored copy of the full Devkit. If the canonical playbook cannot be retrieved, continue to follow the local project instructions and report that limitation rather than pretending the canonical document was read.
